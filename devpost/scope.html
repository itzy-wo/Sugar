Sugar

A cute but savage chatbot that pulls students out of tutorial hell by teaching Python and SQL through curated, genuinely useful projects they actually build.

🌶️ The Unique Kernel

Cute on the outside, savage on the inside.

Sugar delivers bite-sized explanations in plain English, guides you through a curated, genuinely useful project (like a practical Python tool or SQL database), and playfully roasts you whenever you submit wrong answers—turning dry theory into active, memorable building sessions.

🎯 Who It's For

Students and beginner coders stuck in "tutorial hell" who know basic syntax from endless video lectures, but freeze when trying to write real code from scratch.

The Shift: Moving away from passive video-watching to typing real code in response to prompt challenges.

✨ Inspiration & Identity

Aesthetic: "Normal cute"—charming, clean, welcoming, and warm without being babyish or overly pink.

Personality: Playful roaster. Sharp, witty, and savage when you make silly mistakes, but always encouraging you back on track.

🗺️ The User Journey & Core Loop

📦 Scope Boundaries

  • Single-Page Chat Interface: Clean, charming "normal cute" styling with instant conversational responsiveness.
  • 2 Curated Tracks: 1 genuinely useful Python utility project and 1 practical SQL database project.
  • Savage & Warm Feedback: Distinctive witty roasts for mistaken code + clear hints to guide them forward.
  • 1 Guided Project + 1 Take-Home Challenge: Hands-on build loop during the session, and an uninspected challenge project prompt at the finish.
  • Dynamic Theme/Interest Selection: Allowing arbitrary user themes (e.g. anime, sports) once core tracks are solid.
  • Real Code Sandbox: In-browser runtime execution environment (e.g., Pyodide / SQLite WebAssembly).
  • Automated Challenge Grading: Inspecting the post-session take-home projects.
  • User Accounts & Persistence: Saving student progress, badges, and past roast history across sessions.
  • Arbitrary Open-Ended Interest Prompts: Streamlined in the POC to curated, high-impact projects to eliminate setup friction and guarantee quality.
  • Multi-window IDE / File Tree: Cut to keep the student focused strictly in the chatbox for the hackathon proof-of-concept.
  • Babyish / Over-the-top Pink Kawaii: Cut in favor of balanced, approachable, "normal cute" design.
  • Complex User Auth & Cloud Database: Cut to guarantee a zero-friction, fast 1-minute demo.

🎬 What "Working" Looks Like (The 60-Second Demo)

1
Launch Sugar: Greeted by a clean, friendly chat interface with Sugar's welcoming introduction.
2
Select Curated Project: User picks a track (e.g. practical Python project).
3
The Savage Beat: Sugar sets up the practical project; user inputs a wrong answer and Sugar drops a hilarious, friendly roast with a guiding hint.
4
Success & Wrap-up: User corrects the code, Sugar celebrates and completes the project, and delivers the independent challenge prompt.
