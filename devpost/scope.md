# Sugar

A cute but savage chatbot that pulls students out of tutorial hell by teaching Python and SQL through curated, genuinely useful projects they actually build step-by-step.

## The Unique Kernel
Cute on the outside, savage on the inside: Sugar delivers dead-simple, plain-English explanations and playfully roasts you when you get answers wrong, teaching you to write code step-by-step for a concrete, useful project instead of getting bogged down in open-ended setups or dry theory.

## Who It's For
Students and beginners stuck in "tutorial hell" who know basic theory from endless video lectures, but freeze when trying to write real code from scratch and want guided, practical building experience.

## The Core Loop
1. The student opens Sugar and picks what they want to build (e.g. a Python utility or a SQL database project).
2. Sugar introduces the curated project and asks the student to write the first step in the chatbox.
3. The student submits their code:
   - If wrong: Sugar drops a funny, savage roast and nudges them in plain English.
   - If right: Sugar cheers them on and moves to the next building block.
4. On completing the mini-project, Sugar gives them an uninspected take-home project prompt to build independently.

## Inspiration & Identity
- Personality: Friendly, humorous, and unapologetically savage when you mess up—yet warm and easy to understand.
- Look and feel: "Normal cute"—approachable, clean, and charming, without being excessively pink, kawaii, or babyish.

## Why This Matters to the Learner
The learner knows firsthand how easy it is to get trapped in theoretical tutorials without building anything, and wants practical experience building their own chatbot alongside an AI coding agent.

## What "Working" Looks Like
A 60-second screen recording showing:
1. Landing on Sugar's cute, welcoming chat interface.
2. Selecting a track (e.g. Python practical project).
3. Sugar introducing the curated project and asking for the first code snippet.
4. Submitting an incorrect answer to trigger Sugar's signature roasting reaction.
5. Submitting the right code, completing the mini-project, and getting the final independent challenge.

## The POC Boundary
- Clean, focused chatbox interface.
- 2 curated tracks: 1 useful Python project and 1 useful SQL project.
- In-chat answer checking with Sugar's signature witty roast-and-guide responses.
- 1 interactive guided project + 1 post-session independent challenge prompt.

## Later
- Live in-browser code execution sandbox.
- Open-ended user interest / theme selection (custom prompts).
- Automated code inspection for the take-home project.
- User accounts and session history.
- Additional subjects (JavaScript, Web Dev, etc.).

## Explicitly Cut
- Open-ended arbitrary interest generation for the PoC (streamlined into curated, highly useful projects to ensure reliable quality and zero friction).
- Multi-window IDE / code editor (everything happens right in the chatbox for the hackathon).
- Babyish / pink kawaii visual theme (intentionally "normal cute" and polished).
- Heavy authentication or server database requirements.
