Sugar — Technical Blueprint

Client-side single-page architecture powered by in-browser WebAssembly engines (sql.js + Pyodide) and a custom voice & roast state machine.

📦 Component Architecture & File Mapping

Splash & Preloader index.html + css/vintage-theme.css
Implements: prd.md > Screens and Layout (Surface 1)

Welcoming mascot animation with "welcome hehe :0" intro. Warms up the WASM binary asynchronously in the background so the user never experiences lag once they enter.

Chat Workspace & Input Controller index.html + js/app.js
Implements: prd.md > Screens and Layout (Surface 2)

Chronological conversation stream with styled Sugar bubbles, code blocks, multiline textarea, and instant action chips for hint and help.

SQL Execution Engine js/sql-engine.js
Implements: prd.md > Track 2: SQL — Event Management System

Uses in-memory sql.js to run student SQL commands. Inspects database schema for CREATE TABLE events, checks row counts for INSERT INTO, and checks result sets for SELECT. Passes SQLite error strings straight to voice.js.

Python Engine (Phase 2 Layer) js/python-engine.js
Implements: prd.md > Track 1: Python — Quiz Application

Executes Python in Pyodide. Tests behavior by asserting list structure, looping logic, and score calculations without failing on whitespace variations.

Voice & Roast Engine js/voice.js (Source: VOICE.md)
Implements: prd.md > Feedback & Roast Engine & VOICE.md

Translates runtime errors into Sugar's signature older-sibling roast copy. Teases the query, never the student. Tracks consecutive errors and triggers the reveal after 3 attempts. Zero emojis on error messages.

🚀 Where It Runs & Verification

  • Zero Build Setup: Double-click index.html or run npx serve . / python -m http.server.
  • GitHub Pages: Publish directly from main branch root with 1 click in repo settings.
  • 60-Second Demo: Preloaded WASM allows immediate, fluid, bug-free recording without network latency.

🛡️ Key Failure Safeguards

  • WASM Preloader: Splash screen absorbs the initial engine download so chat starts warm.
  • Frustration Barrier: Attempt 3 automatically reveals the working code with encouragement.
  • Execution Timeout: 3-second guard catches infinite loops in user scripts.
