✅ Observable Acceptance Criteria

  • Loading Screen: Mascot and welcome splash appear on load, transitioning smoothly into the workspace.
  • Track Switching: User can switch between Python Quiz App and SQL Event System at any time.
  • Error Handling: Wrong submissions trigger humorous roasts + corrective feedback.
  • Special Triggers: hint shows clues, help shows snippets, and nonsense triggers Sugar's blunt warning.
  • Completion Display: Full code block renders alongside the uninspected take-home challenge prompt.

🚫 Cuts & Deferred Boundaries

  • No Arbitrary Theme Inputs: Kept strictly to curated high-impact Quiz App and Event System.
  • No Multi-window IDE: Everything happens inside the chatbox for speed and simplicity.
  • No Backend Database / Auth: Zero signup friction; client-side single page app.
  • No WASM Code Runner: Validates logic through pattern/keyword verification rather than running arbitrary binaries in POC.
